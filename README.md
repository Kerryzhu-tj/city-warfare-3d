# 巷战 3D · 封锁区

一款可直接在浏览器中运行的 **第一人称 3D 城市巷战** 游戏。红蓝两支小队在废弃街区展开团队死斗，使用手枪、自动步枪、冲锋枪、狙击枪、手榴弹、闪光手雷，也能拔出匕首或施展武术进行近身格斗。画面为风格化低多边形，强调紧张交火与战术走位，**不含血腥内容**。

> 玩家 + 3 名 AI 队友（红军或蓝军）对抗 4 名敌军。率先取得 **20 次击杀**，或在 **6 分钟** 结束时比分领先的一方获胜。

---

## 快速开始

### 方式一：直接打开（最简单）

双击 `index.html`，用现代浏览器（Chrome / Edge / Firefox / Safari）打开即可。

### 方式二：本地静态服务器（推荐）

在本目录执行：

```bash
python3 -m http.server 8000
```

然后访问 <http://127.0.0.1:8000/>。

- 不需要安装依赖、不需要构建、不需要联网。
- 首次进入请点击画面或「进入封锁区」以获得鼠标锁定与音频播放权限。
- 鼠标锁定是可选增强：若浏览器拒绝或暂不允许锁定，对局不会暂停，可**按住鼠标左键拖动**转动视角继续游玩。
- 游戏全部资源（模型、贴图、音效、音乐）均由代码在本地实时生成，无外部下载。

## 玩法要点

- **团队死斗**：击杀敌军为所属队伍加分；被击倒后 3.4 秒重新部署，AI 队友与敌人也会自动复活。
- **护盾与恢复**：出生后短暂无敌；脱离战斗约 6 秒后生命值自动恢复。
- **手榴弹会伤到自己**：投掷后立刻换位，别站在爆炸半径里。
- **闪光手雷**：不要直视爆点；被闪白后视野会短暂过曝并影响瞄准。
- **狙击枪**：开镜后移动散布极大，建议蹲下或静止射击。
- **AI 行为**：敌人会沿街区寻路、探头、点射、投雷，并在贴身时拔刀。高难度下枪法与协同更强。

### 难度

| 难度 | 特点 |
| --- | --- |
| 新兵 | 散布大、伤害低、反应慢，适合熟悉操作 |
| 老兵 | 默认难度，攻守有序、会使用手雷 |
| 精英 | 精准火力、移动更快、投雷更频繁 |

## 技术说明

- 纯前端：HTML + CSS + 原生 JavaScript + Three.js r128（本地文件）。
- 渲染：WebGL；第一人称武器放在独立场景渲染，避免穿墙与光源过曝。
- 地图：程序化生成 16 栋建筑、街区障碍、路灯与天空，附带 AABB 碰撞与 A* 导航网格。
- 音频：Web Audio API 实时合成枪声、爆炸、脚步、环境声与紧张氛围音乐，可静音。
- 美术：全部由 Canvas 贴图与基础几何体程序化生成，无外部图片或音频素材。
- 存档：仅用 `localStorage` 保存音量、灵敏度、难度等本地设置，不是云存档。

### 浏览器要求

- 支持 WebGL 的现代桌面浏览器（Chrome / Edge / Firefox / Safari 新版本）。
- 建议 1280×720 以上分辨率；低端设备可降低画质，帧率不足时优先关闭其他标签页。
- 音频需用户交互后才能播放，这是浏览器自动播放策略的要求。

## 已知限制

- 仅支持单机对战 AI，没有联网多人、账号或排行榜。
- AI 为脚本化行为，不具备真人级别的战术创造力。
- 触控操作为基础版本，未针对手机做完整平衡。
- 指针锁定可能被浏览器策略、iframe 或安全设置拒绝；此时游戏不会暂停，视角改为「按住左键拖动」，功能完整但手感不如锁定模式。
- 无血腥特效；命中反馈以火花、烟尘、冲击波与受击提示呈现。
- 未做完整无障碍模式（如色盲辅助、字幕化音效），但界面文本对比度与键位提示已尽量清晰。
